One-line: the brand's pill button — gradient primary for the single main action, outline secondary beside it, solid-white tertiary when the background is pure black.

\`\`\`jsx
<Button variant="primary" size="lg">Book A Free Webinar</Button>
<Button variant="secondary">Request a Callback</Button>
<Button variant="link" icon="→">Explore</Button>
\`\`\`

Variants: \`primary\` (gradient + glow, one per section), \`secondary\` (1.5px #3A4258 outline), \`tertiary\` (white fill, ink text), \`link\` (cyan text + arrow, no container). Sizes sm/md/lg. Hover lifts 2px and deepens the glow.
